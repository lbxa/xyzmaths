Use the conventional notation $E(x)=e^x$. Show that for any $a>0$ there is some $b\in\mathbb{R}$ such that $a=e^b$ which allows us to define the function

$$
a^x=e^{bx},\qquad x\in\mathbb{R}.
$$

Classify the function $a^x$ in terms of $a$ when it is increasing, decreasing, or constant.

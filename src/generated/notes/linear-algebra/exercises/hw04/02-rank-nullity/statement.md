Answer each question using the rank-nullity theorem.

:::list

1.  **(a)** Suppose $L:V\to W$, where $\dim V=7$, $\dim W=5$, and $\dim\ker L=3$. Find $\operatorname{rank}L$. Is $L$ injective? Is it surjective?

2.  **(b)** Prove that every injective linear map $T:\mathbb{R}^4\to\mathbb{R}^4$ is an isomorphism.

3.  **(c)** Prove that no linear map from $\mathbb{R}^6$ to $\mathbb{R}^4$ can be injective.

4.  **(d)** Prove that no linear map from $\mathbb{R}^3$ to $\mathbb{R}^5$ can be surjective.

:::

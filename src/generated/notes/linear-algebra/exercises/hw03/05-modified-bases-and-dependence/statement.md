Let $\{u,v,w\}$ be a basis of a real vector space $V$.

:::list

1.  **(a)** Show that $\{u+v+w,v+w,w\}$ is also a basis.

2.  **(b)** Is it possible that a subset $\{v_1,v_2,v_3\}\subset V$ is linearly dependent but the set $\{v_2+v_3,v_3+v_1,v_1+v_2\}$ is linearly independent?

:::

Let $F(x)$ be a continuous function which maps the interval $[a,b]$ into itself. Prove that $F$ has a fixed point in $[a,b]$. That is, there is some $c\in[a,b]$ such that $F(c)=c$. Use your result to prove that for any $n\in\mathbb{N}$ there is some $x\in(0,1)$ such that

$$
x=\frac{1}{1+x^n}.
$$

Find $x$ for $n=1$.

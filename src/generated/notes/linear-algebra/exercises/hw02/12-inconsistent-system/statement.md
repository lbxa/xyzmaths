Work over $\mathbb F=\mathbb{R}$ or $\mathbb{C}$. Consider the system

$$
2x-3y=5,\qquad x+y=-1,\qquad 3x+5y=0,
$$

:::list

1.  **(a)** Show that this system has no solution.

2.  **(b)** Find matrices $A,v,$ and $b$ such that the system is equivalent to

    $$
    Av=b.
    $$

3.  **(c)** Find the set of all $b\in\mathbb F^3$ for which $Av=b$ has a solution, and show that for each such $b$, the solution is unique.

:::

True or false? Explain. If false, provide a counterexample.

:::list

1.  **3.1.** If a matrix has one eigenvector, then it has infinitely many eigenvectors.

2.  **3.2.** Every matrix over a field $\mathbb F$ has at least one eigenvalue in $\mathbb F$.

3.  **3.3.** Similar matrices always have the same eigenvectors.

4.  **3.4.** If two matrices have the same eigenvalues, then they are similar.

:::
